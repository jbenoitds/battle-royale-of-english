itch.io packages (web version). Upload one zip per language as an HTML game on itch.io.
battle_royale_en.zip = Battle Royale of English, battle_royale_fr.zip = Bataille Royale du Français.
Each zip = index.html + favicon.png + fw_xx_ws.tar (plain tar: itch.io counts the files inside an .apk and refuses more than 1000).
Built with pygbag 0.9.3 from main@c51a78b. Viewport 1060x700.
